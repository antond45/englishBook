# English File: практика

Веб-приложение для изучения английского по структуре курса Oxford **English File 4th edition**. В нём есть вход в аккаунт, уроки строго по порядку, теория, чтение и аудирование.

Все уровни заполнены полностью. В каждом уроке есть теория, упражнения, чтение и аудирование; в каждом юните — Practical English (на B2 — Colloquial English) и Revise & Check.

| Уровень | Учебник | Юнитов | Упражнений | Чтение | Аудирование |
|---|---|---|---|---|---|
| A1 | Beginner | 12 | 288 | 42 | 54 |
| A2 | Elementary | 12 | 251 | 41 | 48 |
| B1 | Pre-Intermediate | 12 | 252 | 42 | 47 |
| B2 | Upper-Intermediate | 10 | 150 | 25 | 30 |

Всего 941 упражнение.

## Как устроено прохождение
- Без входа приложение не открывается. Прогресс хранится на сервере, поэтому он сохраняется на любом устройстве.
- Уровни независимы друг от друга, начать можно с любого.
- Внутри уровня уроки открываются **строго по порядку**. Урок засчитывается, когда сделаны все его упражнения, а общий результат **не ниже 80%** (по лучшим попыткам). Тогда сохраняется дата прохождения и открывается следующий урок.
- Кнопка «Продолжить» ведёт к первому непройденному уроку.

## Задания
- **Теория** — объяснение правила на русском с таблицами и примерами. Кнопка 🔊 рядом с примером озвучивает его.
- **Упражнения**: вставить слово, выбрать ответ, True/False, сопоставить, составить предложение, переписать, видео.
- **📖 Чтение** — свой текст и вопросы к нему.
- **🎧 Аудирование** — диалог озвучивает голос браузера (Web Speech API). Есть обычная и медленная скорость. Текст аудио можно открыть только после проверки ответов. Если в браузере нет английского голоса, вместо аудио показывается текст. В Chrome, Edge и Safari английские голоса обычно есть.

## Озвучка (Kokoro)
Аудирования и примеры из теории озвучены заранее моделью [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) (лицензия Apache 2.0). Есть три набора голосов, их выбирают в настройках приложения (⚙ в верхней строке):
- **Британский** (по умолчанию): `bf_emma` — диктор и женские роли, `bf_isabella`, `bm_george`, `bm_fable`, `bm_lewis`;
- **Британский, мужской диктор**: то же, но теорию читает `bm_george`;
- **Американский**: `af_heart`, `af_bella`, `am_michael`, `am_fenrir`, `am_puck`.

В диалогах у каждого персонажа свой голос. Файлы лежат в `public/audio/` вместе с `manifest.json`. Если в выбранном наборе нет файла для текста, берётся британский набор, а если нет и его — голос браузера. Голос браузера можно выбрать и вручную.

Ещё в настройках: скорость по умолчанию (0.75–1.25×, её можно поменять и прямо в плеере), громкость и автоповтор аудирования (1–3 раза подряд). Настройки хранятся в браузере на этом устройстве.

После правок в текстах аудирований или примеров запусти:
```bash
npm run audio
```
Скрипт озвучит только новые и изменённые тексты во всех наборах и удалит файлы, которые больше не нужны. Можно озвучить только часть наборов: `npm run audio -- --sets uk`. Один набор с нуля — примерно 25 минут на обычном процессоре, видеокарта не нужна. Наборы голосов настраиваются в `VOICE_SETS` в начале `tools/tts/generate.py`.

Установка окружения (один раз). Нужен [uv](https://docs.astral.sh/uv/). Kokoro работает на Python 3.10–3.12:
```bash
uv python install 3.12 --install-dir tools/tts/python
uv venv tools/tts/.venv --python 3.12
uv pip install --python tools/tts/.venv -r tools/tts/requirements.txt --index-strategy unsafe-best-match
```
Модель (около 330 МБ) скачается в `tools/tts/hf-cache` при первом запуске. Голоса и паузы настраиваются в начале `tools/tts/generate.py`.

## Картинки (OpenMoji)
Картинки — иконки [OpenMoji](https://openmoji.org/), лицензия [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Авторство указано внизу каждой страницы. Где они используются:
- **«Картинка → слово»** (`type: "picture"`): 40 упражнений на лексику — страны, предметы, цвета, еда, профессии, погода, одежда, транспорт, животные и т. д. На A1–A2 слово выбирают из списка (`mode: "choice"`), на B1–B2 пишут сами (`mode: "type"`).
- **Иллюстрации** к текстам для чтения и аудированиям: поле `image` у задания.
- **Обложки юнитов**: поле `cover` в `level.json`.

Картинка в контенте задаётся обычным эмодзи, например `"image": "🏨"`. После добавления новых эмодзи выполни `npm run emoji`: скрипт скопирует нужные иконки в `public/emoji` и удалит лишние. Тест проверяет, что у каждого эмодзи есть иконка.

## Авторские права
Тексты, аудио и видео Oxford в приложение не копируются: все упражнения, тексты и диалоги написаны специально для него. Официальные материалы открываются по ссылкам:
- **English File 4e Online Practice** (`englishfile4e.oxfordonlinepractice.com`) — видео уроков и Practical English, вход по коду из учебника.
- **Student's Site** (`elt.oup.com/student/englishfile/…`) — бесплатные упражнения. Сайт сделан для 3-го издания, но темы в основном совпадают.
- **Oxford English Hub** и **Learner's Bookshelf** — e-book и материалы, если они входят в твой комплект.

Названия уроков и порядок тем в `level.json` приблизительные: сверь их с оглавлением своего учебника.

## Запуск одним кликом (Windows)
Дважды щёлкни `Запустить English File.cmd` в папке проекта. Он соберёт сайт, запустит сервер и откроет в браузере http://localhost:3000. Чтобы остановить приложение, закрой чёрное окно. При первом запуске он сам установит зависимости. Нужен только Node.js 24. Если приложение уже запущено, повторный запуск не стартует второй сервер, а просто откроет браузер.

## Запуск для разработки
Нужен **Node.js 24** или новее: сервер использует встроенный SQLite и запускает TypeScript без сборки.

```bash
npm install
npm run dev        # сервер API (порт 3001) + сайт (http://localhost:5173)
npm test           # тесты: сервер, проверка ответов, порядок уроков, контент
npm run validate-content   # проверка всех JSON с контентом
```

База лежит в `data/app.db` (в git не попадает).

## Запуск на сервере
```bash
npm install
npm run build      # собирает сайт в dist/
npm start          # один процесс: и API, и сайт, порт 3001 (или PORT)
```
Переменные окружения:
- `PORT` — порт (по умолчанию 3001).
- `DB_FILE` — путь к файлу базы (по умолчанию `data/app.db`). На хостинге он должен лежать на постоянном диске.
- `SECURE_COOKIES=1` — включить, когда сайт работает по HTTPS.

Подойдёт любой VPS или хостинг с постоянным диском (Render, Railway, Fly.io с volume и т. п.).

## Как добавить контент
Контент лежит в `content/<уровень>/`:
- `level.json` — учебник, юниты и уроки.
- `file-NN.json` — теория (`theory`), упражнения (`exercises`) и видео (`videos`) юнита. Пример: `content/a1/file-01.json`.

Типы упражнений: `gap-fill`, `multiple-choice`, `true-false`, `matching`, `word-order`, `transform`, `video-task`, `reading`, `listening`. Схемы описаны в `src/content/schema.ts`. После правок запусти `npm run validate-content`: команда покажет файл и место ошибки.

## Устройство
- `server/` — Express и SQLite: регистрация, вход (пароли хешируются через scrypt, сессия в httpOnly-cookie, ограничение попыток входа) и API прогресса.
- `src/progress/store.ts` — прогресс в памяти браузера, синхронизируется с сервером.
- `src/stats.ts` — порог 80%, порядок уроков, «Продолжить».
